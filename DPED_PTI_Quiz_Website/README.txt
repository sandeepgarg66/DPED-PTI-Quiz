D.P.Ed. / PTI MCQ Practice Test

Files:
- index.html: website structure and questions
- style.css: design and mobile responsive layout
- script.js: answer checking, score and restart button

How to open:
1. Extract the ZIP file.
2. Keep all four files together in the same folder.
3. Double-click index.html to open in a browser.

The quiz includes 40 questions, answer feedback, score tracking and a restart button. It is responsive for mobile screens. A public shareable link requires hosting, for example GitHub Pages.
